# Independent integration review (in progress)

Baseline `221c870`, inspected evolving uncommitted candidate. Files were changing concurrently, so line locations below identify the inspected version rather than a frozen final diff. This is a review of source paths and selected tests, not a deployment or GUI acceptance.

1. **P1: child permissions do not inherit parent ceiling.** At review time `agent.py` initialized `permission_ceilings` but no code populated it; `agent_tool.py` constructed fresh checkers/rule engines at each child path. A parent deny can therefore be absent from a child's decision. Fix all foreground/background/teammate/fork paths and verify parent deny cannot be relaxed by child policy.
2. **P1: Glob/Grep path check uses search pattern.** `permissions/checker.py` passes `extract_content` to path sandbox; `permissions/rules.py` maps these tools to `pattern`, although actual I/O uses `path`. Read-only reproduction on the review candidate: sandbox rejects an absolute outside-project target but `checker.check(Grep(), {pattern:'needle', path:outside})` returns allow. Check the canonical actual target and symlink descendants, without treating an application policy as an OS sandbox.
3. **P1: length-truncated summaries can commit.** `context/manager.py` rejects length stop only if the client exposes it; OpenAI-compatible `client.py` produced `end_turn` for the usage chunk regardless of `choice.finish_reason`. A length-limited stream can therefore produce a nonempty truncated summary that replaces history. Test the real adapter event sequence and persist only a complete response.
4. **P1: exhausted children are reported completed.** `Agent._run` records `limit_reached` and returns, while `run_to_completion` returns normally and searches prior assistant history; foreground child, background manager and teammate call sites then mark complete. A child that stops after a tool call can return partial or prior-turn text as its result. Propagate and persist actual stop reason; test resumed/forked history and iteration exhaustion.
5. **P1: hooks see different path/cwd.** Serial `agent.py` pre/post hooks receive unnormalized arguments before `_execute_tool` canonicalizes them; command hooks run using inherited process cwd. In a worktree, a hook can inspect or change the parent `same.txt` while the actual tool acts on the child file. Use the same execution context and canonical arguments for hooks, permissions, I/O and audit.
6. **P1: structured CU data not delivered or retained through all paths.** Provider serializers used plain `ToolResultBlock.content`, dropping structured content/details; team transcript save/load omitted them. The candidate stores these fields in standard session JSONL, but that alone does not prove the next real model request sees them. Preserve typed raw receipts/artifact references through intended serialization, fork, compaction, resume and TUI; honor provider-supported formats.
7. **P2: structured blocks can bypass output budgets.** `context/manager.py` carried full `content_blocks` unchanged while replacing the text content with a bounded preview. If a serializer emits original blocks, it can re-send the full result or duplicate it. Project bounded display/content separately from the retained raw artifact and test aggregate budget.

Selected tests were run with `--timeout=10`: 151 passed and 11 failed. All 11 failing test IDs are already failures in frozen `evidence/baseline-bounded.xml`; no additional failing IDs were found in this selected subset. See `cu-root-review.xml` and `.log`; machine paths were redacted. This does not mean the integration is correct: the source findings above need targeted regression tests and re-review after fixes.
